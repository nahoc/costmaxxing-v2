# Landing page

Scope: the costmaxxing landing page (`site/`), visitor mode Persuade. Audience: claude.ai Team and Enterprise Owners. Action: install the Chrome extension. Proof: the report itself, computed by core from a synthetic example team and labeled as an example. Constraints: static HTML/CSS/JS, self-hosted fonts, no third-party requests, store link or zip by STORE_URL.

## Direction contract

THESIS: The page is a 1984 one-bit desktop where the team's Claude bill is a window and the subsidy is a system alert. It refuses the category default of a gradient hero, a product screenshot in a browser frame, and a feature grid.

OWN-WORLD: Pure black and white pixels. Every gray is an ordered dither: a 50% checker owns the desktop, stripes mark active title bars, diagonal zebra marks overspend. One-pixel-unit chrome with close boxes, size boxes, hard shadows. Jersey 15 for title bars and display, Geist Pixel for body. Two-color pixel icons. Atkinson-dithered public-domain photography (Paul Strand, Wall Street, 1915).

STORY: The desktop boots into a team's bill: a Read Me asks what the Claude team would cost at API prices, Team Bill shows an example team at $2.6k against $298 on open-weight models, and an alert asks what you will do when the subsidies end. Its default button installs the extension.

FIRST VIEWPORT: Menu bar across the top. Read Me upper left holding the headline at display scale. Team Bill on the right with figures, seat line, and zebra-marked people. The Strand painting peeks behind. Icons down the right edge. The alert sits at the visual center with the thick-ringed default button as the primary action.

FORM: early one-bit desktop, first dealt challenger of the bolder re-roll, seed key e39fa731. Signature: windows zoom open from their icons in a short boot, drag with a dotted outline, and any figure opens a Get Info window citing its source. Motion is stepped only; reduced motion shows the settled desktop. Raises: the dither owns the viewport; overspend wears zebra; Get Info cites sources; windows drift on separate planes while scrolling, snapped to whole pixels.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
