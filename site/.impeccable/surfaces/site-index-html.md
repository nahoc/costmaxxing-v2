# Landing page

Scope: the openmaxxing landing page (`site/`), visitor mode Persuade. Audience: claude.ai Team and Enterprise Owners. Takeaway: how much a team can save by moving from Anthropic to open-weight models. Action: install the Chrome extension; the CLI is not featured. Proof: the Team Bill, computed by core from a synthetic example team and labeled as an example. Credit: "Made with <3 by Cohan Carpentier". Constraints: static HTML/CSS/JS, self-hosted fonts, no third-party requests, store link or zip by STORE_URL.

## Direction contract

THESIS: The page is a 1984 two-color desktop where the team's Claude bill is a window and the savings question is a system dialog. It refuses the category default of a gradient hero, a product screenshot in a browser frame, and a feature grid.

OWN-WORLD: Dark purple ink (#2e1065) on white, nothing else. Every middle tone is an ordered dither: a 50% checker owns the desktop, stripes mark the active title bar, diagonal zebra marks overspend. One-pixel-unit chrome with close boxes, size boxes, hard shadows. Jersey 15 and Geist Pixel at three sizes only. Two-color pixel icons from one SVG sprite. Atkinson-dithered public-domain photography (Paul Strand, Wall Street, 1915).

STORY: The desktop boots into one question, how much the team can save by moving from Anthropic to open-weight models, in a dialog whose default button installs the extension. Beside it, an example Team Bill answers with a yearly savings figure. Reference windows below explain how it works, the providers, and the permissions; the page closes on "What will you do when the subsidies end?".

FIRST VIEWPORT: Menu bar across the top. The savings dialog vertically centered on the left with the question at display size and the thick-ringed install button. The Team Bill on the right, not overlapping. Icons down the right edge; Wall Street starts closed behind its icon.

FORM: early one-bit desktop, first dealt challenger of the bolder re-roll, seed key e39fa731, refined to two colors at the user's request. Signature: windows zoom open from their icons in a short boot, drag with a dotted outline, and any figure opens a Get Info window citing its source. Motion is stepped only, nothing moves on scroll, and reduced motion shows the settled desktop.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
